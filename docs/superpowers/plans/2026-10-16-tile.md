# Tile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tile, a one-app-at-a-time Lua shell for CC:Tweaked 1.20.1, with a paged grid of square icons that runs on computers, pocket computers, and monitors.

**Architecture:** Pure Lua modules under `os/` do layout, color, app discovery, and session changes with no Minecraft calls, so `lua5.1` and `lua5.4` can test them on the host. `os/main.lua` is the only event loop: it picks the terminal, draws the bar itself, and runs each app as a coroutine whose `os.pullEvent` yields back to Tile. That is what keeps Home clickable while `edit` or the CraftOS shell is running. `install.lua` sits beside the `os` folder, copies it to the in-game `/os`, and writes `startup.lua`.

**Tech Stack:** Lua 5.1-compatible source (CC:Tweaked 1.20.1's Cobalt runtime, exercised on the host with both `lua5.1` and `lua5.4`), CC terminal / window / fs / peripheral APIs, no Java, no extra Lua libraries.

## Global Constraints

- CC:Tweaked 1.20.1 only. Lua programs. No Java mod.
- Devices: normal and advanced computers, normal and advanced pocket computers, and monitors. No turtles.
- One app on screen at a time. No overlapping windows and no drag-to-reorder.
- A computer is 51×19. A pocket is 26×20. A monitor keeps whatever text scale the player already set. Tile never calls `setTextScale`.
- Home-screen cell is 5 characters wide and 3 tall. The icon is 3×2, centered horizontally in the cell, with the name under it. One blank column and one blank row sit between cells, not after the last cell.
- A screen smaller than 15×10 is too small for the grid.
- Icon tones are only white, black, light gray, and one accent stored as blue (`b` in the `.nfp`). Advanced screens recolor that blue. Basic screens draw it gray. Stray colors also become gray on a basic screen.
- Built-in accents: Files blue, Shell lime, Settings orange. User apps default to cyan. An unknown accent name becomes cyan. `grey` and `lightGrey` are accepted aliases.
- The name under an icon and in the bar is at most 5 characters. Files and Shell fit. Settings' tile label is `Sett.` because `Settings` does not fit.
- The home bar shows `Tile` on the left. Page arrows `<` and `>` appear at the right only when there is more than one page. An open app's bar shows `Home` in columns 1–4, then the app label. There is no clock.
- Chrome responds to left click on a computer or pocket, and to `monitor_touch` on the active monitor. Arrow keys do not move a home-screen cursor.
- Built-ins ship in `/os/builtins` and are listed first: Files, Shell, Settings. User apps are in-game folders `/apps/<name>/` with `main.lua`. Optional `label`, `icon.nfp`, and `accent`. Folders without `main.lua` are skipped. Then user apps sort by label.
- Files opens at `/`, directories first, then files, A to Z. A `.lua` file runs on top of Files. Any other file opens in `/rom/programs/edit.lua` on top of Files. Quitting that child returns to Files. `..` goes up, and it is hidden at `/`. Files does not copy, rename, or delete.
- Shell is `/rom/programs/shell.lua` inside the app area. `exit` returns to the grid.
- Settings shows `Screen: Color` or `Screen: Gray`, lists `This screen` plus attached monitors, saves the choice to `/.tile`, and applies it immediately. Exit to CraftOS asks `Yes` / `No` first.
- `/.tile` holds one line, `display=terminal` or `display=<peripheral name>`. Reinstall must not delete it. A missing file means "the terminal Tile was started on".
- A missing saved monitor clears the setting and uses the computer. A saved monitor smaller than 15×10 shows the too-small message on that monitor and the full UI on the computer when the computer is large enough. The message button `Use computer` clears the saved monitor.
- When the picture is on a monitor, the computer screen shows `Showing on monitor`.
- App errors stay under the bar until Home. Ctrl+T inside an app returns to the grid. Ctrl+T on the grid leaves Tile so CraftOS can start. Tile never calls `os.reboot` or `os.shutdown`.
- `install.lua` copies the sibling `os` directory to `/os`, asks `Replace startup.lua? (y/n)` before replacing an existing startup file, and writes `shell.run("/os/main.lua")`.
- Color follows the terminal being drawn on (`isColor()`), not the computer block.

| `os/display.lua` | Choose the UI terminal, the too-small monitor, and the status terminal |
| `os/events.lua` | Classify raw CC events |
| `os/session.lua` | Pure screen / page / stack reducer |
| `os/draw.lua` | Paint the bar, grid, errors, and the too-small message |
| `os/fileslist.lua` | Directory listing rules |
| `os/filesui.lua` | Files clicks and drawing |
| `os/settingsui.lua` | Settings clicks and drawing |
| `os/runner.lua` | Load an app coroutine with a hooked `os.pullEvent` |
| `os/main.lua` | Boot, draw, dispatch, exit |
| `os/builtins/*/main.lua` | Files, Shell, Settings programs |
| `os/builtins/*/{label,accent,icon.nfp}` | Built-in tile art |
| `install.lua` | In-game installer |
| `README.md` | How to test on the host and install in a world |

Modules return tables. They read the global `colors` table. They take `fs`, `term`, and `peripheral` as arguments instead of reaching for hardware, except `os/main.lua` and `install.lua`, which pass the real APIs in.

Host tests call `dofile` on these files. `tests/run.lua` sets `package.path` so a module may `require("layout")` and the other Tile modules.

`tests/harness.lua`

```lua
local unpack = unpack or table.unpack

local harness = {}
local tests = {}
local failed = false

local function deepEqual(a, b)
  if type(a) ~= type(b) then
    return false
  end
  if type(a) ~= "table" then
    return a == b
  end
  for k, v in pairs(a) do
    if not deepEqual(v, b[k]) then
      return false
    end
  end
  for k in pairs(b) do
    if a[k] == nil then
      return false
    end
  end
  return true
end

local function dump(v)
  if type(v) ~= "table" then
    return tostring(v)
  end
  local parts = {}
  for k, value in pairs(v) do
    parts[#parts + 1] = tostring(k) .. "=" .. dump(value)
  end
  table.sort(parts)
  return "{" .. table.concat(parts, ",") .. "}"
end

function harness.test(name, fn)
  tests[#tests + 1] = { name = name, fn = fn }
end

function harness.assertEq(actual, expected, message)
  if actual ~= expected then
    error((message or "assertEq") .. "\n  actual:   " .. dump(actual) .. "\n  expected: " .. dump(expected), 2)
  end
end

function harness.assertDeep(actual, expected, message)
  if not deepEqual(actual, expected) then
    error((message or "assertDeep") .. "\n  actual:   " .. dump(actual) .. "\n  expected: " .. dump(expected), 2)
  end
end

function harness.failLoad()
  failed = true
end

function harness.run()
  for i = 1, #tests do
    local ok, err = pcall(tests[i].fn)
    if ok then
      io.write("PASS " .. tests[i].name .. "\n")
    else
      failed = true
      io.write("FAIL " .. tests[i].name .. "\n" .. tostring(err) .. "\n")
    end
  end
  if failed then
    os.exit(1)
  end
end

return harness
```

local colors = {

  orange = 2,

  pink = 64,
  gray = 128,

  red = 16384,

}
colors.grey = colors.gray
colors.lightGrey = colors.lightGray
_G.colors = colors

local function fakeTerm(w, h, isColor)
  local fg = colors.white
  local bg = colors.black
  local curX, curY = 1, 1
  local buf = {}
  local term = {}

  local function cell(x, y)
    buf[y] = buf[y] or {}
    buf[y][x] = buf[y][x] or { " ", fg, bg }
    return buf[y][x]
  end

  function term.getSize()
    return w, h
  end

  function term.setCursorPos(x, y)
    curX, curY = x, y
  end

  function term.getCursorPos()
    return curX, curY
  end

  function term.setTextColor(c)
    fg = c
  end

  function term.setTextColour(c)
    fg = c
  end

  function term.setBackgroundColor(c)
    bg = c
  end

  function term.setBackgroundColour(c)
    bg = c
  end

  function term.getTextColor()
    return fg
  end

  function term.getBackgroundColor()
    return bg
  end

  function term.isColor()
    return isColor and true or false
  end

  function term.isColour()
    return term.isColor()
  end

  function term.write(text)
    text = tostring(text)
    for i = 1, #text do
      if curX >= 1 and curX <= w and curY >= 1 and curY <= h then
        local slot = cell(curX, curY)
        slot[1] = text:sub(i, i)
        slot[2] = fg
        slot[3] = bg
      end
      curX = curX + 1
    end
  end

  function term.clear()
    buf = {}
    for y = 1, h do
      for x = 1, w do
        cell(x, y)
        buf[y][x] = { " ", fg, bg }
      end
    end
  end

  function term.clearLine()
    if curY < 1 or curY > h then
      return
    end
    for x = 1, w do
      buf[curY][x] = { " ", fg, bg }
    end
  end

  function term.setCursorBlink()
  end

  function term.scroll()
  end

  function term.line(y)
    local out = {}
    for x = 1, w do
      out[x] = (buf[y] and buf[y][x] and buf[y][x][1]) or " "
    end
    return table.concat(out)
  end

  function term.cell(x, y)
    local slot = buf[y] and buf[y][x]
    if not slot then
      return " ", fg, bg
    end
    return slot[1], slot[2], slot[3]
  end

  return term
end

return {
  colors = colors,
  fakeTerm = fakeTerm,
}

```lua
local NAMES = {
  white = colors.white,
  orange = colors.orange,
  magenta = colors.magenta,
  lightBlue = colors.lightBlue,
  yellow = colors.yellow,
  lime = colors.lime,
  pink = colors.pink,
  gray = colors.gray,
  grey = colors.gray,
  lightGray = colors.lightGray,
  lightGrey = colors.lightGray,
  cyan = colors.cyan,
  purple = colors.purple,
  blue = colors.blue,
  brown = colors.brown,
  green = colors.green,
  red = colors.red,
  black = colors.black,
}

local theme = {}

function theme.resolveAccent(name, isColor)
  local accent = NAMES[name or ""] or colors.cyan
  if not isColor then
    return colors.gray
  end
  return accent
end

function theme.remap(picture, isColor, accentName)
  local accent = theme.resolveAccent(accentName, isColor)
  local out = {}
  for y = 1, #picture do
    out[y] = {}
    for x = 1, #picture[y] do
      local pixel = picture[y][x]
      if pixel == colors.blue then
        out[y][x] = accent
      elseif not isColor and pixel ~= colors.white and pixel ~= colors.black and pixel ~= colors.lightGray and pixel ~= colors.gray then
        out[y][x] = colors.gray
      else
        out[y][x] = pixel
      end
    end
  end
  return out
end

return theme
```

- [ ] **Step 3: Write `os/layout.lua`**

```lua
local layout = {
  CELL_W = 5,
  CELL_H = 3,
  ICON_W = 3,
  ICON_H = 2,
  GAP = 1,
  MIN_W = 15,
  MIN_H = 10,
}

local function fit(space, cell, gap)
  if space < cell then
    return 0
  end
  return math.floor((space + gap) / (cell + gap))
end

function layout.metrics(w, h)
  local tooSmall = w < layout.MIN_W or h < layout.MIN_H
  local contentH = h - 1
  if contentH < 0 then
    contentH = 0
  end
  local cols = 0
  local rows = 0
  if not tooSmall then
    cols = fit(w, layout.CELL_W, layout.GAP)
    rows = fit(contentH, layout.CELL_H, layout.GAP)
  end
  return {
    w = w,
    h = h,
    tooSmall = tooSmall,
    cols = cols,
    rows = rows,
    pageSize = cols * rows,
    contentY = 2,
    contentH = contentH,
  }
end

function layout.pageCount(appCount, pageSize)
  if pageSize <= 0 or appCount <= 0 then
    return 1
  end
  return math.ceil(appCount / pageSize)
end

function layout.cellOrigin(col, row)
  local x = 1 + col * (layout.CELL_W + layout.GAP)
  local y = 2 + row * (layout.CELL_H + layout.GAP)
  return x, y
end

function layout.hit(metrics, x, y, page, appCount)
  if metrics.tooSmall or y < metrics.contentY or appCount <= 0 then
    return nil
  end
  local strideX = layout.CELL_W + layout.GAP
  local strideY = layout.CELL_H + layout.GAP
  local localY = y - metrics.contentY
  local col = math.floor((x - 1) / strideX)
  local row = math.floor(localY / strideY)
  local inX = (x - 1) % strideX
  local inY = localY % strideY
  if col < 0 or row < 0 or col >= metrics.cols or row >= metrics.rows then
    return nil
  end
  if inX >= layout.CELL_W or inY >= layout.CELL_H then
    return nil
  end
  local index = (page - 1) * metrics.pageSize + row * metrics.cols + col + 1
  if index < 1 or index > appCount then
    return nil
  end
  return index
end

function layout.barHit(w, x, y, mode, pages)
  if y ~= 1 then
    return nil
  end
  if mode == "app" and x >= 1 and x <= 4 then
    return "home"
  end
  if mode == "home" and pages > 1 and x == w - 2 then
    return "prev"
  end
  if mode == "home" and pages > 1 and x == w then
    return "next"
  end
  return nil
end

function layout.tooSmallHit(x, y)
  if y == 5 and x >= 1 and x <= 12 then
    return "use_computer"
  end
  return nil
end

return layout
```

local HEX = {
  ["0"] = colors.white,
  ["1"] = colors.orange,
  ["2"] = colors.magenta,
  ["3"] = colors.lightBlue,
  ["4"] = colors.yellow,
  ["5"] = colors.lime,
  ["6"] = colors.pink,
  ["7"] = colors.gray,
  ["8"] = colors.lightGray,
  ["9"] = colors.cyan,
  a = colors.purple,
  b = colors.blue,
  c = colors.brown,
  d = colors.green,
  e = colors.red,
  f = colors.black,
}

local icon = {}

function icon.parse(text)
  if type(text) ~= "string" then
    return nil, "icon must be text"
  end
  local rows = {}
  for line in (text .. "\n"):gmatch("(.-)\r?\n") do
    if line ~= "" then
      rows[#rows + 1] = line
    end
  end
  if #rows ~= 2 then
    return nil, "icon must be 2 rows"
  end
  local picture = {}
  for y = 1, 2 do
    if #rows[y] ~= 3 then
      return nil, "icon must be 3 columns"
    end
    picture[y] = {}
    for x = 1, 3 do
      local pixel = HEX[rows[y]:sub(x, x)]
      if not pixel then
        return nil, "bad icon color"
      end
      picture[y][x] = pixel
    end
  end
  return picture
end

return icon

```lua
local icon = require("icon")

local apps = {}

local BUILTINS = {
  { id = "files", fallback = "Files", accent = "blue" },
  { id = "shell", fallback = "Shell", accent = "lime" },
  { id = "settings", fallback = "Sett.", accent = "orange" },
}

function apps.shorten(text)
  text = tostring(text or "")
  text = text:gsub("\r", "")
  text = text:match("^%s*(.-)%s*$") or ""
  if text == "" then
    return ""
  end
  return text:sub(1, 5)
end

local function readLine(fs, path)
  local handle = fs.open(path, "r")
  if not handle then
    return nil
  end
  local line = handle.readLine()
  handle.close()
  return line
end

local function loadIcon(fs, path)
  local handle = fs.open(path, "r")
  if not handle then
    return nil
  end
  local text = handle.readAll()
  handle.close()
  return icon.parse(text)
end

local function addApp(out, spec)
  local label = apps.shorten(spec.label)
  if label == "" then
    label = apps.shorten(spec.fallback or spec.id)
  end
  out[#out + 1] = {
    id = spec.id,
    label = label,
    accent = spec.accent or "cyan",
    path = spec.path,
    icon = spec.icon,
    folder = spec.folder or spec.id,
  }
end

function apps.discover(fs, osDir)
  local found = {}
  for i = 1, #BUILTINS do
    local spec = BUILTINS[i]
    local dir = fs.combine(fs.combine(osDir, "builtins"), spec.id)
    local path = fs.combine(dir, "main.lua")
    if fs.exists(path) and not fs.isDir(path) then
      addApp(found, {
        id = spec.id,
        fallback = spec.fallback,
        label = readLine(fs, fs.combine(dir, "label")) or spec.fallback,
        accent = readLine(fs, fs.combine(dir, "accent")) or spec.accent,
        path = path,
        icon = loadIcon(fs, fs.combine(dir, "icon.nfp")),
        folder = spec.id,
      })
    end
  end

  local users = {}
  if fs.exists("apps") and fs.isDir("apps") then
    local names = fs.list("apps")
    for i = 1, #names do
      local folder = names[i]
      local dir = fs.combine("apps", folder)
      local path = fs.combine(dir, "main.lua")
      if fs.isDir(dir) and fs.exists(path) and not fs.isDir(path) then
        local accent = readLine(fs, fs.combine(dir, "accent")) or "cyan"
        users[#users + 1] = {
          id = folder,
          fallback = folder,
          label = readLine(fs, fs.combine(dir, "label")) or folder,
          accent = accent,
          path = path,
          icon = loadIcon(fs, fs.combine(dir, "icon.nfp")),
          folder = folder,
        }
      end
    end
  end
  table.sort(users, function(a, b)
    local left = apps.shorten(a.label):lower()
    local right = apps.shorten(b.label):lower()
    if left == right then
      return a.folder:lower() < b.folder:lower()
    end
    return left < right
  end)
  for i = 1, #users do
    addApp(found, users[i])
  end
  return found
end

return apps
```

The accent file is kept whole on purpose: `theme.resolveAccent` treats an unknown name as cyan, and `apps.shorten` is only for the visible label. A test already expects `red` to stay `red`.

local function large(term)
  if not term or not term.getSize then
    return false
  end
  local w, h = term.getSize()
  return w >= 15 and h >= 10
end

local function computerActive()
  return { kind = "computer", name = "terminal" }
end

local function monitorActive(name)
  return { kind = "monitor", name = name }
end

function display.resolve(api, saved)
  local native = api.native()
  local current = api.current()
  if saved == nil then
    local term = current or native
    if large(term) then
      if term == native then
        return {
          mode = "ui",
          ui = term,
          active = computerActive(),
          displayName = "terminal",
        }
      end
      return {
        mode = "ui",
        ui = term,
        status = native,
        active = monitorActive("current"),
        displayName = "current",
      }
    end
    if term ~= native and large(native) then
      return {
        mode = "split",
        ui = native,
        message = term,
        messageSide = "current",
        active = computerActive(),
        displayName = "terminal",
      }
    end
    return {
      mode = "message",
      message = term,
      active = term == native and computerActive() or monitorActive("current"),
      displayName = "terminal",
    }
  end

  if saved == "terminal" then
    if large(native) then
      return {
        mode = "ui",
        ui = native,
        active = computerActive(),
        displayName = "terminal",
      }
    end
    return {
      mode = "message",
      message = native,
      active = computerActive(),
      displayName = "terminal",
    }
  end

  local monitor = api.wrap(saved)
  if not monitor then
    return {
      mode = "ui",
      ui = native,
      active = computerActive(),
      displayName = "terminal",
      clearSaved = true,
    }
  end
  if not large(monitor) then
    if large(native) and native ~= monitor then
      return {
        mode = "split",
        ui = native,
        message = monitor,
        messageSide = saved,
        active = computerActive(),
        displayName = saved,
      }
    end
    return {
      mode = "message",
      message = monitor,
      messageSide = saved,
      active = monitorActive(saved),
      displayName = saved,
    }
  end
  return {
    mode = "ui",
    ui = monitor,
    status = native ~= monitor and native or nil,
    active = monitorActive(saved),
    displayName = saved,
  }
end

return display

local events = {}

local function pointer(x, y)
  return { kind = "pointer", x = x, y = y }
end

function events.classify(active, event)
  local name = event[1]
  if name == "terminate" then
    return { kind = "terminate" }
  end
  if active.kind == "monitor" then
    if name == "monitor_touch" and event[2] == active.name then
      return pointer(event[3], event[4])
    end
    if name == "mouse_click" or name == "mouse_drag" or name == "mouse_up" or name == "mouse_scroll" or name == "monitor_touch" then
      return { kind = "ignore" }
    end
  else
    if name == "mouse_click" and event[2] == 1 then
      return pointer(event[3], event[4])
    end
    if name == "mouse_click" or name == "monitor_touch" then
      return { kind = "ignore" }
    end
    if name == "mouse_drag" or name == "mouse_up" or name == "mouse_scroll" then
      return {
        kind = "pointer_pass",
        name = name,
        button = event[2],
        x = event[3],
        y = event[4],
      }
    end
  end
  return { kind = "pass", event = event }
end

return events

```lua
local layout = require("layout")

local session = {}

function session.new()
  return {
    screen = "home",
    page = 1,
    stack = {},
    error = nil,
  }
end

local function copyStack(stack)
  local out = {}
  for i = 1, #stack do
    out[i] = stack[i]
  end
  return out
end

local function withPage(state, ctx)
  local pages = layout.pageCount(#ctx.apps, ctx.metrics.pageSize)
  if state.page > pages then
    state.page = pages
  end
  if state.page < 1 then
    state.page = 1
  end
  return pages
end

function session.reduce(state, event, ctx)
  local nextState = {
    screen = state.screen,
    page = state.page,
    stack = copyStack(state.stack),
    error = state.error,
  }

  if event.type == "terminate" then
    if #nextState.stack == 0 then
      return nextState, "exit_os"
    end
    nextState.stack = {}
    nextState.screen = "home"
    nextState.error = nil
    return nextState, "go_home"
  end

  if ctx.metrics.tooSmall or nextState.screen == "toosmall" then
    nextState.screen = "toosmall"
    if event.type == "click" and layout.tooSmallHit(event.x, event.y) == "use_computer" then
      return nextState, "clear_display"
    end
    return nextState, nil
  end

  if event.type == "child_done" then
    if #nextState.stack > 0 then
      table.remove(nextState.stack)
    end
    nextState.error = nil
    if #nextState.stack == 0 then
      nextState.screen = "home"
      return nextState, "go_home"
    end
    nextState.screen = "app"
    return nextState, "resume"
  end

  if event.type == "child_error" then
    nextState.error = event.message or "error"
    nextState.screen = "app"
    return nextState, "show_error"
  end

  if event.type == "push" then
    nextState.stack[#nextState.stack + 1] = {
      path = event.path,
      args = event.args or {},
      label = event.label or "App",
    }
    nextState.screen = "app"
    nextState.error = nil
    return nextState, "launch"
  end

  if event.type == "click" then
    local pages = withPage(nextState, ctx)
    local mode = nextState.screen == "app" and "app" or "home"
    local bar = layout.barHit(ctx.metrics.w, event.x, event.y, mode, pages)
    if bar == "home" then
      nextState.stack = {}
      nextState.screen = "home"
      nextState.error = nil
      return nextState, "go_home"
    end
    if bar == "prev" then
      if nextState.page > 1 then
        nextState.page = nextState.page - 1
      end
      return nextState, nil
    end
    if bar == "next" then
      if nextState.page < pages then
        nextState.page = nextState.page + 1
      end
      return nextState, nil
    end
    if nextState.screen == "home" and nextState.error == nil then
      local index = layout.hit(ctx.metrics, event.x, event.y, nextState.page, #ctx.apps)
      if index then
        local app = ctx.apps[index]
        nextState.stack = {
          {
            path = app.path,
            args = {},
            label = app.label,
            id = app.id,
          },
        }
        nextState.screen = "app"
        nextState.error = nil
        return nextState, "launch"
      end
    end
  end

  withPage(nextState, ctx)
  return nextState, nil
end

return session
```

local layout = require("layout")
local theme = require("theme")

local draw = {}

local function fill(term, bg, fg)
  term.setBackgroundColor(bg)
  term.setTextColor(fg)
  term.clear()
  term.setCursorPos(1, 1)
end

local function put(term, x, y, text, bg, fg)
  term.setBackgroundColor(bg)
  term.setTextColor(fg)
  term.setCursorPos(x, y)
  term.write(text)
end

function draw.blank(term)
  fill(term, colors.black, colors.white)
end

function draw.status(term)
  fill(term, colors.black, colors.white)
  term.write("Showing on monitor")
end

function draw.bar(term, spec)
  local w = term.getSize()
  term.setBackgroundColor(colors.gray)
  term.setTextColor(colors.white)
  term.setCursorPos(1, 1)
  term.clearLine()
  term.setCursorPos(1, 1)
  if spec.mode == "app" then
    term.write("Home " .. (spec.label or ""))
  else
    term.write("Tile")
  end
  if spec.mode == "home" and spec.pages and spec.pages > 1 then
    put(term, w - 2, 1, "<", colors.gray, colors.white)
    put(term, w, 1, ">", colors.gray, colors.white)
  end
end

local function paintIcon(term, x, y, app, isColor)
  if app.icon then
    local picture = theme.remap(app.icon, isColor, app.accent)
    for iy = 1, #picture do
      for ix = 1, #picture[iy] do
        put(term, x + ix - 1, y + iy - 1, " ", picture[iy][ix], picture[iy][ix])
      end
    end
    return
  end
  for iy = 0, 1 do
    for ix = 0, 2 do
      put(term, x + ix, y + iy, " ", colors.white, colors.black)
    end
  end
  local letter = (app.label:sub(1, 1) or "?"):upper()
  put(term, x + 1, y, letter, colors.white, colors.black)
end

local function paintLabel(term, x, y, label)
  label = label or ""
  if #label > 5 then
    label = label:sub(1, 5)
  end
  local pad = math.floor((5 - #label) / 2)
  local text = string.rep(" ", pad) .. label .. string.rep(" ", 5 - pad - #label)
  put(term, x, y, text, colors.white, colors.black)
end

function draw.home(term, metrics, appList, page, isColor)
  fill(term, colors.white, colors.black)
  if metrics.pageSize <= 0 then
    return
  end
  local start = (page - 1) * metrics.pageSize
  for row = 0, metrics.rows - 1 do
    for col = 0, metrics.cols - 1 do
      local index = start + row * metrics.cols + col + 1
      local app = appList[index]
      if app then
        local x, y = layout.cellOrigin(col, row)
        paintIcon(term, x + 1, y, app, isColor)
        paintLabel(term, x, y + 2, app.label)
      end
    end
  end
end

function draw.error(term, message)
  fill(term, colors.white, colors.black)
  local w = term.getSize()
  term.write("App error")
  term.setCursorPos(1, 2)
  term.write(tostring(message or ""):sub(1, w))
end

function draw.tooSmall(term, showButton)
  fill(term, colors.white, colors.black)
  term.write("Screen too small")
  term.setCursorPos(1, 2)
  term.write("Lower text scale")
  term.setCursorPos(1, 3)
  term.write("or add blocks")
  if showButton then
    term.setCursorPos(1, 5)
    term.write("Use computer")
  end
end

return draw

local unpack = unpack or table.unpack

local runtime = {}

function runtime.pack(...)
  return { n = select("#", ...), ... }
end

function runtime.unpack(packed)
  if packed == nil then
    return
  end
  return unpack(packed, 1, packed.n or #packed)
end

function runtime.unpackList(list)
  return unpack(list, 1, #list)
end

function runtime.loadWithEnv(src, chunkName, env)
  if not setfenv then
    return load(src, chunkName, "t", env)
  end
  local fn, err = loadstring(src, chunkName)
  if not fn then
    return nil, err
  end
  setfenv(fn, env)
  return fn
end

return runtime

```lua
local runtime = require("runtime")

local runner = {}

local function readAll(fs, path)
  local handle = fs.open(path, "r")
  if not handle then
    return nil, "missing " .. tostring(path)
  end
  local text = handle.readAll()
  handle.close()
  return text
end

function runner.launch(spec)
  local env = setmetatable({}, { __index = _G })
  env.term = spec.win
  env.os = setmetatable({}, { __index = os })

  function env.os.pullEventRaw(filter)
    while true do
      local packed = runtime.pack(coroutine.yield("pull", filter))
      if packed[1] == "terminate" or filter == nil or packed[1] == filter then
        return runtime.unpack(packed)
      end
    end
  end

  function env.os.pullEvent(filter)
    local packed = runtime.pack(env.os.pullEventRaw(filter))
    if packed[1] == "terminate" then
      error("Terminated", 0)
    end
    return runtime.unpack(packed)
  end

  env.tile = {
    display = spec.displayName or "terminal",
  }

  function env.tile.push(path, args, label)
    coroutine.yield("push", path, args or {}, label)
  end

  function env.tile.setDisplay(name)
    coroutine.yield("set_display", name)
  end

  function env.tile.exit()
    coroutine.yield("exit_os")
  end

  function env.tile.load(path)
    local src, err = readAll(spec.fs, path)
    if not src then
      return nil, err
    end
    return runtime.loadWithEnv(src, "@" .. path, env)
  end

  local src, err = readAll(spec.fs, spec.path)
  if not src then
    error(err, 0)
  end
  local fn, loadErr = runtime.loadWithEnv(src, "@" .. spec.path, env)
  if not fn then
    error(loadErr, 0)
  end
  local args = spec.args or {}
  return {
    co = coroutine.create(function()
      fn(runtime.unpackList(args))
    end),
    env = env,
    win = spec.win,
    started = false,
    fs = spec.fs,
  }
end

function runner.pump(frame, event)
  local packed
  if not frame.started then
    frame.started = true
    packed = runtime.pack(coroutine.resume(frame.co))
  elseif event == nil then
    packed = runtime.pack(coroutine.resume(frame.co))
  else
    packed = runtime.pack(coroutine.resume(frame.co, runtime.unpackList(event)))
  end
  if not packed[1] then
    local message = tostring(packed[2])
    if message == "Terminated" then
      return { kind = "terminated" }
    end
    return { kind = "error", message = message }
  end
  if coroutine.status(frame.co) == "dead" then
    return { kind = "exit" }
  end
  local yielded = packed[2]
  if yielded == "push" then
    return {
      kind = "push",
      path = packed[3],
      args = packed[4] or {},
      label = packed[5],
    }
  end
  if yielded == "set_display" then
    return { kind = "set_display", name = packed[3] }
  end
  if yielded == "exit_os" then
    return { kind = "exit_os" }
  end
  return { kind = "wait" }
end

return runner
```

local fileslist = {}

local function isRoot(path)
  return path == nil or path == "" or path == "/"
end

function fileslist.parent(path)
  if isRoot(path) then
    return "/"
  end
  local trimmed = path:gsub("/+$", "")
  local parent = trimmed:match("^(.*)/[^/]+$")
  if not parent or parent == "" then
    return "/"
  end
  return parent
end

function fileslist.child(path, name)
  if isRoot(path) then
    return "/" .. name
  end
  return path:gsub("/+$", "") .. "/" .. name
end

function fileslist.list(fs, path)
  local names = fs.list(path)
  local dirs = {}
  local files = {}
  for i = 1, #names do
    local name = names[i]
    local full = fileslist.child(path, name)
    if fs.isDir(full) then
      dirs[#dirs + 1] = { name = name, kind = "dir" }
    elseif name:sub(-4):lower() == ".lua" then
      files[#files + 1] = { name = name, kind = "lua" }
    else
      files[#files + 1] = { name = name, kind = "text" }
    end
  end
  table.sort(dirs, function(a, b)
    return a.name:lower() < b.name:lower()
  end)
  table.sort(files, function(a, b)
    return a.name:lower() < b.name:lower()
  end)
  local out = {}
  if not isRoot(path) then
    out[1] = { name = "..", kind = "up" }
  end
  for i = 1, #dirs do
    out[#out + 1] = dirs[i]
  end
  for i = 1, #files do
    out[#out + 1] = files[i]
  end
  return out
end

return fileslist

local fileslist = require("fileslist")

local filesui = {}

local function capacity(h, count)
  local pager = count > (h - 1)
  local rows = pager and (h - 2) or (h - 1)
  if rows < 1 then
    rows = 1
  end
  return rows, pager
end

function filesui.draw(term, model, fs)
  local w, h = term.getSize()
  local entries = fileslist.list(fs, model.path)
  local rows, pager = capacity(h, #entries)
  local pages = math.max(1, math.ceil(#entries / rows))
  if model.page > pages then
    model.page = pages
  end
  if model.page < 1 then
    model.page = 1
  end
  term.setBackgroundColor(colors.white)
  term.setTextColor(colors.black)
  term.clear()
  term.setCursorPos(1, 1)
  term.write(model.path:sub(1, w))
  local start = (model.page - 1) * rows
  for i = 1, rows do
    local entry = entries[start + i]
    if entry then
      local text = entry.name
      if entry.kind == "dir" then
        text = text .. "/"
      end
      term.setCursorPos(1, i + 1)
      term.write(text:sub(1, w))
    end
  end
  if pager then
    term.setCursorPos(1, h)
    term.write("Prev")
    term.setCursorPos(w - 3, h)
    term.write("Next")
  end
end

function filesui.click(model, term, x, y, fs)
  local w, h = term.getSize()
  local entries = fileslist.list(fs, model.path)
  local rows, pager = capacity(h, #entries)
  local pages = math.max(1, math.ceil(#entries / rows))
  if pager and y == h then
    if x <= 4 and model.page > 1 then
      model.page = model.page - 1
    end
    if x >= w - 3 and model.page < pages then
      model.page = model.page + 1
    end
    return model, nil
  end
  if y < 2 or (pager and y >= h) then
    return model, nil
  end
  local index = (model.page - 1) * rows + (y - 1)
  local entry = entries[index]
  if not entry then
    return model, nil
  end
  if entry.kind == "up" then
    model.path = fileslist.parent(model.path)
    model.page = 1
    return model, nil
  end
  if entry.kind == "dir" then
    model.path = fileslist.child(model.path, entry.name)
    model.page = 1
    return model, nil
  end
  local full = fileslist.child(model.path, entry.name)
  if entry.kind == "lua" then
    return model, { type = "push", path = full, args = {}, label = "Files" }
  end
  return model, {
    type = "push",
    path = "/rom/programs/edit.lua",
    args = { full },
    label = "Files",
  }
end

return filesui

      term.setCursorPos(1, 4 + i)
      term.write((mark .. " " .. item.text):sub(1, w))
    end
  end

local config = require("config")
local display = require("display")
local events = require("events")
local session = require("session")
local draw = require("draw")
local runner = require("runner")
local layout = require("layout")
local runtime = require("runtime")

local main = {}

local function makeWindow(api, parent)
  local w, h = parent.getSize()
  if h < 2 then
    return api.window(parent, 1, 1, math.max(1, w), 1)
  end
  return api.window(parent, 1, 2, w, h - 1)
end

local function context(appList, ui)
  local w, h = ui.getSize()
  return {
    apps = appList,
    metrics = layout.metrics(w, h),
  }
end

function main.run(api)
  local saved = config.read(api.fs)
  local view = display.resolve(api, saved)
  if view.clearSaved then
    config.write(api.fs, "terminal")
  end
  local state = session.new()
  local frames = {}
  local frame = nil
  local window = nil

  local function listApps()
    return apps.discover(api.fs, api.osDir or "/os")
  end

  local function paint()
    if view.mode == "message" then
      draw.tooSmall(view.message, false)
      return
    end
    if view.message then
      draw.tooSmall(view.message, true)
    end
    if view.status then
      draw.status(view.status)
    end
    local ui = view.ui
    local ctx = context(listApps(), ui)
    if ctx.metrics.tooSmall then
      draw.tooSmall(ui, false)
      return
    end
    if state.screen == "home" then
      draw.home(ui, ctx.metrics, ctx.apps, state.page, ui.isColor())
      draw.bar(ui, {
        mode = "home",
        pages = layout.pageCount(#ctx.apps, ctx.metrics.pageSize),
        page = state.page,
      })
      return
    end
    local top = state.stack[#state.stack]
    draw.bar(ui, { mode = "app", label = top and top.label or "" })
    if state.error and window then
      draw.error(window, state.error)
    end
  end

  local function attachWindow()
    window = nil
    if not view.ui then
      return
    end
    local w, h = view.ui.getSize()
    local metrics = layout.metrics(w, h)
    if metrics.tooSmall or state.screen ~= "app" then
      return
    end
    window = makeWindow(api, view.ui)
    window.setBackgroundColor(colors.white)
    window.setTextColor(colors.black)
    window.clear()
    if frame then
      frame.win = window
      frame.env.term = window
      frame.env.tile.display = view.displayName or "terminal"
    end
  end

  local dispatch

  local function launchTop()
    local top = state.stack[#state.stack]
    attachWindow()
    frame = runner.launch({
      fs = api.fs,
      path = top.path,
      args = top.args or {},
      win = window,
      displayName = view.displayName or "terminal",
    })
    frames[#frames + 1] = frame
    return dispatch(runner.pump(frame, nil))
  end

  function dispatch(result)
    if not result then
      return nil
    end
    if result.kind == "wait" then
      return nil
    end
    if result.kind == "exit_os" then
      return "exit"
    end
    local ctx = view.ui and context(listApps(), view.ui) or {
      apps = {},
      metrics = layout.metrics(1, 1),
    }
    if result.kind == "error" then
      state = session.reduce(state, { type = "child_error", message = result.message }, ctx)
      paint()
      return nil
    end
    if result.kind == "terminated" then
      local effect
      state, effect = session.reduce(state, { type = "terminate" }, ctx)
      if effect == "exit_os" then
        return "exit"
      end
      frames = {}
      frame = nil
      window = nil
      paint()
      return nil
    end
    if result.kind == "exit" then
      local effect
      state, effect = session.reduce(state, { type = "child_done" }, ctx)
      frames[#frames] = nil
      frame = frames[#frames]
      if effect == "resume" and frame then
        frame.env.tile.display = view.displayName or "terminal"
        return dispatch(runner.pump(frame, nil))
      end
      frame = nil
      window = nil
      paint()
      return nil
    end
    if result.kind == "push" then
      state = session.reduce(state, {
        type = "push",
        path = result.path,
        args = result.args,
        label = result.label,
      }, ctx)
      return launchTop()
    end
    if result.kind == "set_display" then
      config.write(api.fs, result.name)
      view = display.resolve(api, result.name)
      if view.clearSaved then
        config.write(api.fs, "terminal")
      end
      attachWindow()
      paint()
      if frame then
        frame.env.tile.display = view.displayName or result.name
        return dispatch(runner.pump(frame, nil))
      end
    end
    return nil
  end

  local function forward(contentEvent)
    if frame and state.screen == "app" and not state.error then
      return dispatch(runner.pump(frame, contentEvent))
    end
    return nil
  end

  paint()

  while true do
    local packed = runtime.pack(api.pullEventRaw())
    if packed[1] == nil then
      return "stop"
    end
    if view.mode == "split" and packed[1] == "monitor_touch" and packed[2] == view.messageSide then
      if layout.tooSmallHit(packed[3], packed[4]) == "use_computer" then
        config.write(api.fs, "terminal")
        if view.message then
          draw.blank(view.message)
        end
        view = display.resolve(api, "terminal")
        attachWindow()
        paint()
      end
    else
      local active = view.active or { kind = "computer", name = "terminal" }
      local class = events.classify(active, packed)
      local ctx = view.ui and context(listApps(), view.ui) or {
        apps = {},
        metrics = layout.metrics(view.message and view.message.getSize() or 1, 1),
      }
      if class.kind == "terminate" then
        local effect
        state, effect = session.reduce(state, { type = "terminate" }, ctx)
        if effect == "exit_os" then
          return "exit"
        end
        frames = {}
        frame = nil
        window = nil
        paint()
      elseif class.kind == "pointer" then
        local effect
        state, effect = session.reduce(state, { type = "click", x = class.x, y = class.y }, ctx)
        if effect == "clear_display" then
          config.write(api.fs, "terminal")
          view = display.resolve(api, "terminal")
          attachWindow()
          paint()
        elseif effect == "go_home" then
          frames = {}
          frame = nil
          window = nil
          paint()
        elseif effect == "launch" then
          frames = {}
          frame = nil
          local exited = launchTop()
          paint()
          if exited == "exit" then
            return "exit"
          end
        elseif state.screen == "app" and frame and not state.error and class.y >= 2 then
          local exited = forward({ "mouse_click", 1, class.x, class.y - 1 })
          if exited == "exit" then
            return "exit"
          end
          paint()
        else
          paint()
        end
      elseif class.kind == "pointer_pass" and class.y and class.y >= 2 then
        local exited = forward({ class.name, class.button, class.x, class.y - 1 })
        if exited == "exit" then
          return "exit"
        end
      elseif class.kind == "pass" then
        local exited = forward(packed)
        if exited == "exit" then

        end
      end
    end
  end
end

end

```lua
local install = {}

local function norm(path)
  path = tostring(path or "")
  return path:gsub("^/+", ""):gsub("/+$", "")
end

local function copyTree(fs, source, dest)
  if fs.isDir(source) then
    if norm(dest) ~= "" then
      fs.makeDir(dest)
    end
    local names = fs.list(source)
    for i = 1, #names do
      copyTree(fs, fs.combine(source, names[i]), fs.combine(dest, names[i]))
    end
    return
  end
  local handle = fs.open(source, "r")
  local data = handle.readAll()
  handle.close()
  local parent = fs.getDir(dest)
  if parent ~= "" and not fs.exists(parent) then
    fs.makeDir(parent)
  end
  local out = fs.open(dest, "w")
  out.write(data)
  out.close()
end

function install.run(fs, sourceDir, ask)
  local source = fs.combine(sourceDir, "os")
  local target = "/os"
  if norm(source) ~= norm(target) then
    if fs.exists(target) then
      fs.delete(target)
    end
    copyTree(fs, source, target)
  end
  local startup = "/startup.lua"
  if fs.exists(startup) then
    local answer = ask("Replace startup.lua? (y/n)")
    if not answer or answer:lower() ~= "y" then
      return "kept"
    end
  end
  local handle = fs.open(startup, "w")
  handle.write("shell.run(\"/os/main.lua\")\n")
  handle.close()
  return "replaced"
end

local function runningAsProgram()
  return shell and shell.getRunningProgram and fs.getName(shell.getRunningProgram()) == "install.lua"

Tile is a Lua shell for the Minecraft mod CC:Tweaked on Minecraft 1.20.1. It opens to a grid of square icons. One app fills the screen at a time. The same program runs on a normal computer, an advanced computer, a pocket computer, an advanced pocket computer, and a monitor.

## Install it on a computer

Tile's files live in this project until you copy them onto an in-game computer. Each computer has its own files. The mod also stores them in the world folder at `computercraft/computer/<id>/`.

1. Copy `install.lua` and the `os` folder onto a floppy, or into that computer's save folder while the world is closed.
2. In the computer, run:

```
/disk/install.lua
```

Use the path where `install.lua` actually is. If `startup.lua` already exists, Tile asks `Replace startup.lua? (y/n)`.
3. Reboot the computer. CC:Tweaked runs `startup.lua`, which runs `/os/main.lua`. Tile is now what opens on every boot.

You can start it once without installing by running `/os/main.lua` after the `os` folder is already on the computer.

Exit to CraftOS from Settings lasts until the next boot. The next boot opens Tile again because `startup.lua` is still there.

## Controls

- Click an icon, or the five-character name under it, to open that app.
- The top row is the bar. On the home screen it says `Tile`. When more than one page of icons exists, `<` and `>` sit at the right.
- While an app is open, `Home` is in the first four columns of the bar. Home always returns to the grid.
- Ctrl+T inside an app returns to the grid. Ctrl+T on the grid leaves Tile and drops you into CraftOS.
- Ctrl+R and Ctrl+S stay the mod's reboot and shutdown. Tile does not call them.
- A monitor is clicked in the world. That is a different event from a click inside the computer screen, and Tile listens for the one that matches the screen it is drawing on.
- Keys still come from the computer or pocket screen. Open that screen when an app such as Shell or edit needs the keyboard, even if the picture is on a monitor.

## Screens

Tile draws on the terminal it was started on. `monitor left /os/main.lua` draws on that monitor. Settings can move the picture later. The choice is saved in `/.tile` and survives a reinstall.

Tile does not change a monitor's text scale. A screen smaller than 15×10 characters shows `Screen too small`, `Lower text scale`, and `or add blocks`. If the computer itself is large enough, that message has a `Use computer` button and the computer shows the normal grid. A missing monitor drops back to the computer and clears the saved choice.

A pocket computer uses its own 26×20 screen. A desktop computer uses its own 51×19 screen unless a monitor was selected.

## Apps

Files, Shell, and Settings ship with Tile. Settings appears on the grid as `Sett.` because a cell holds five characters.

- Files starts at `/`. Folders are listed first. A `.lua` file runs. Any other file opens in the normal `edit` program. Leaving that program returns to Files. Inserting or removing a floppy refreshes the list.
- Shell is the normal CraftOS prompt. `exit` returns to the grid.
- Settings shows `Screen: Color` or `Screen: Gray`, lists `This screen` and any attached monitors, and asks before Exit to CraftOS.

Add another app on that in-game computer:

```
/apps/notes/main.lua
/apps/notes/label
/apps/notes/accent
/apps/notes/icon.nfp
```

`main.lua` is required. `label` is the name under the icon, shortened to five characters. `accent` is a CC color name such as `cyan`, `red`, or `lime`. If it is missing or unknown, the accent is cyan.

`icon.nfp` is exactly two lines of three hex digits:

```
0b0
000
```

The digits follow the normal CC paint palette: `0` white, `8` light gray, `f` black, and `b` blue. Blue is the accent placeholder. Tile recolors it on an advanced screen and draws it gray on a basic screen. A missing or broken icon becomes a letter on a white tile.

User apps are listed after the three built-ins, sorted by label. Two computers in one world do not share `/apps`.
